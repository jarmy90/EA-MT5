WINDOWS PROCEDURE
Start at: PS C:\Users\j>

1. Clone the repository.
PS C:\Users\j> git clone https://github.com/jarmy90/EA-MT5.git

2. Enter the folder.
PS C:\Users\j> cd EA-MT5

3. Check Python.
PS C:\Users\j\EA-MT5> py --version

4. Check Node.js.
PS C:\Users\j\EA-MT5> node --version

5. Create the virtual environment.
PS C:\Users\j\EA-MT5> py -m venv .venv

6. Activate the virtual environment.
PS C:\Users\j\EA-MT5> .\.venv\Scripts\Activate.ps1

7. Install Python dependencies.
PS C:\Users\j\EA-MT5> python -m pip install -r requirements.txt

8. Generate a bridge token without displaying it.
PS C:\Users\j\EA-MT5> $env:BRIDGE_TOKEN = [Convert]::ToBase64String((1..48 | ForEach-Object { Get-Random -Maximum 256 }))

9. Add local non-secret settings to .env. Do not paste the token into chat.
PS C:\Users\j\EA-MT5> @'
DATA_SOURCE=bridge
MT5_SERVER=ICMarketsEU-MT5-5
MT5_SYMBOLS=USTEC,XAUUSD
BRIDGE_HOST=127.0.0.1
BRIDGE_PORT=8000
'@ | Set-Content .env

10. Append the generated token to .env without printing it.
PS C:\Users\j\EA-MT5> Add-Content .env ("BRIDGE_TOKEN=" + $env:BRIDGE_TOKEN)

11. Keep MetaTrader 5 open and already connected to the account. Do not enter a password in the dashboard.

12. Start the read-only bridge.
PS C:\Users\j\EA-MT5> .\start_mision_control.bat

13. In a second PowerShell window, test the local health endpoint without a token. It must return 401.
PS C:\Users\j> Invoke-WebRequest http://127.0.0.1:8000/health -UseBasicParsing | Select-Object -ExpandProperty StatusCode

14. Test with the token without printing the token.
PS C:\Users\j> $headers = @{ Authorization = "Bearer $env:BRIDGE_TOKEN" }; Invoke-WebRequest http://127.0.0.1:8000/health -Headers $headers -UseBasicParsing | Select-Object -ExpandProperty StatusCode

15. Install cloudflared.
PS C:\Users\j> winget install --id Cloudflare.cloudflared -e

16. Start a temporary HTTPS tunnel to the local bridge.
PS C:\Users\j> cloudflared tunnel --url http://127.0.0.1:8000

17. Copy only the HTTPS URL ending in trycloudflare.com printed by cloudflared. Do not copy /health or /telemetry.

18. Configure the cloud dashboard privately in Freebuff Settings -> Environment. Set MT5_BRIDGE_HTTP_URL to the copied HTTPS URL and BRIDGE_TOKEN to the local token. Never put either value in Git, README, browser URL, or chat.

19. Restart the dashboard preview/server after saving the environment values.

20. Verify the dashboard changes from SIMULACIÓN to MT5 LIVE and displays real account/position values.

21. Identify each EA using its magic number or comment. Set AGENT_MAP locally with the exact mapping; do not guess. Keep the adapter read-only.

22. To stop the bridge, return to its window and press Ctrl+C. To stop the temporary tunnel, return to its window and press Ctrl+C.
