# Archived Autonomous Business Lab

This directory contains the former Vite/WAWA dashboard and related launch artifacts kept for traceability only.

## Inactive status

- It is not the repository's active web application.
- Do not run files from this directory to start the dashboard.
- The active web application is the root Next.js app started with `START_ORBIT.bat` on port `3000`.
- The local MT5 bridge is started with the root `start_mision_control.bat` on `127.0.0.1:8000`.
- Port `8001` and the `/EA-MT5/` path are not used by the active application.

The live bridge implementation remains outside this archive in `api/` and `mt5_bridge/`.
